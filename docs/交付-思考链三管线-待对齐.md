# 草案：Cursor 风格任务进程（reasoning 压缩 + kind）

**状态**：设计已拍板并开工  
**产品一句**：用户看到的「思考」= **任务执行过程**（跳动进程行），不是长段模型独白。  
**协议一句**：**保留** thinking + tool 进度压缩进同一 `reasoning` 槽（Session 出口贴近 AI 层 OpenAI 形，便于后续层级同构 / 把全过程 reasoning 当上游输入）；用正交 **`kind`** 给 UI 白名单，不靠正文黑名单。

---

## 1. 为什么还压缩进 `reasoning`

上级对齐：不是疏忽，而是为 **Session↔AI 协议同构** 留口——过程流仍是一条 `reasoning`，以后可能整段复用为「上游 AI 输入」；若拆成独立 SSE `type=tool`，同构成本更高。

渲染与协议解耦：协议读 `reasoning`；UI 读 `kind`。

## 2. `kind` 取值（Session 打标）

| kind | 来源 | spa-v2 |
|------|------|--------|
| `thinking` | 上游 `delta.reasoning`（或上游已带 `kind`） | 进程行 → **规划下一步…**（不渲染 thinking 正文） |
| `tool_call` | Session 执行 tool 前 | 进程行 → 工具友好短句（见 §3） |
| `tool_result` | Session 执行 tool 后 | 进程行 → **整理结果…** |

规则写在 **yield 点**（`agent.py` / `schedule_registry.py`），不是扫字符串分类。

## 3. 进程行文案表（必须给定，对标 Cursor）

**原则**：只显示固定短句 + 跳动点；**永不**把 `reasoning` 正文（thinking 独白 / `[Tool Call:]` 原文）渲染进进程行。`kind` 只决定「切到哪一句」。

| 时机 | 触发 | 显示文案 |
|------|------|----------|
| 回合开始 / 等首包 | `progressLabelTurnStart()` | **规划下一步…**（≈ Planning next moves） |
| 模型 thinking | `kind=thinking`（只用信号，丢正文） | **规划下一步…** |
| 调工具 | `kind=tool_call` + 工具名映射 | 见下表；未知 → `调用 {name}…` |
| 工具返回 | `kind=tool_result` | **整理结果…** |
| 开始吐正文 | 首个 `content` delta | **撰写回复…** |
| 回合结束 / 停止 | finally | 清空 |

### 工具名 → 文案（`turnProgress.ts` / `TOOL_LABELS`）

| 工具（示例） | 文案 |
|--------------|------|
| `bash` / `powershell` | 执行命令… |
| `read` | 读取文件… |
| `write` / `edit` | 写入文件… / 编辑文件… |
| `list_dir` / `find_files` | 浏览目录… / 查找文件… |
| `todo` | 更新任务清单… |
| `search` / `web_search` / `fetch` | 检索中… / 拉取网页… |
| `browser_*` | 浏览页面… |
| `feishu_*` | 飞书操作… |
| 其它 | `调用 {name}…` |

词表集中在 spa-v2 `services/turnProgress.ts` 的 `TURN_PROGRESS` + `TOOL_LABELS`；改文案只改该文件。

## 4. 展示壳

流式气泡旁：跳动点 + 上表文案。正文气泡只收 `content`。

## 5. 代码落点

| 层 | 改动 |
|----|------|
| `session/protocol.py` | `REASONING_KIND_*`；`AgentChunk.kind`；`DeltaMessage.kind`；`AiDelta.kind` |
| `session/ai_client.py` | 透传上游 `delta.kind` |
| `session/agent.py` / `schedule_registry.py` | yield 时打 kind |
| `session/channel_adapter.py` | SSE 写出 `kind` |
| `channel/_types.py` / `_core.py` | `ReasoningChunk.kind`；buffer key `reasoning:<kind>` |
| `gateway/_chat_manager.py` | SPA 事件带 `kind` |
| spa-v2 `turnProgress.ts` | **文案表** + kind→label；FocusChatThread 进程行 |

过渡期仍可保留 `[Tool Call:]` 文案（旧剥标记 / 解析工具名）；新 UI 以 `kind` + 上表为准。
