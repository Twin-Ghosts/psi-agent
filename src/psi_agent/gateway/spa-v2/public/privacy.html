隐私政策

生效日期：2026 年 8 月 12 日 · 版本 v1.0

一句话概括：您的任务、对话与文件只存在您自己的电脑上，我们收不到。 云端只保存让您能登录的最小信息 —— 手机号或邮箱，以及您的登录设备记录。

一、我们收集哪些信息

信息用途保存位置
手机号 / 邮箱 作为账号标识，用于注册、登录与找回 云端
昵称、头像 界面展示 云端（昵称）/ 本机
设备标识、操作系统类型、设备名 展示「已登录设备」列表，供您撤销可疑登录 云端
登录时间、最近活跃时间 识别异常登录 云端
发码请求的 IP 与频次 防止短信、邮件接口被盗刷 云端（短期）
任务记录、对话历史、工作区文件、模型密钥 软件功能本身 仅本机，不上传

二、我们不收集什么

  • 不收集您与 AI 的对话内容。
  • 不收集您的工作区文件、文件名或目录结构。
  • 不收集您配置的模型 API 密钥 —— 它保存在本机。
  • 不读取您的通讯录、相册、位置或其他设备权限数据。
  • 不使用您的数据训练模型。

三、第三方服务

为完成验证码发送，我们将必要信息提供给下列服务商，仅限于该次发送所需：

  • 短信：阿里云通信 —— 接收您的手机号以投递验证码短信。
  • 邮件：Resend —— 接收您的邮箱地址以投递验证码邮件。

此外，若您在软件中配置了第三方 AI 模型，您的指令与对话内容将由您的本机直接发往该模型服务商， 不经过我们的服务器。该行为受您与该服务商之间的条款约束，请自行阅读其隐私政策。

四、本机凭证如何保存

登录成功后，凭证保存在您本机的应用数据目录中，并使用操作系统钥匙串（Windows 凭据管理器 / macOS Keychain / Linux Secret Service）中的密钥加密。

若系统钥匙串不可用，软件会在界面上明确提示并以明文保存 —— 这是降级行为而非预期状态。 请注意，凭证的保护边界是操作系统账户，而非单个程序。

五、保存期限

  • 账号信息在您使用账号期间持续保存，直至您注销账号。
  • 验证码仅在有效期内保存，验证通过或过期后立即失效。
  • 发码频次记录仅保留至限频窗口结束。
  • 被撤销的登录设备记录会标记为已撤销，用于安全审计。

六、您的权利

  • 查看：在「账户与设备」中查看您的账号信息与全部登录设备。
  • 更正：可修改昵称。
  • 撤销登录：可移除任一登录设备，被移除设备立即退出登录。
  • 退出登录：清除本机凭证。此操作不会删除任何本地数据。
  • 注销账号：如需删除云端账号及关联标识，请通过官网公示的联系方式申请。

七、未成年人

本软件不面向 14 周岁以下儿童提供账号服务。若您是未成年人，请在监护人同意与指导下使用。

八、政策更新

本政策如有更新，将在本页公布并更新生效日期。涉及信息收集范围实质扩大的变更， 我们将通过客户端显著方式告知并重新征求您的同意。

九、联系我们

如对本政策有疑问，或需要行使上述权利，请通过官网公示的联系方式与我们联系。

另请阅读 《用户服务协议》。
